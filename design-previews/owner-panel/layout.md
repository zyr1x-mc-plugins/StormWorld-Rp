# OWNER / StormWorld

Комплект: 6 экранов 256×256 RGBA и 3 состояния; preview — увеличение 4× NEAREST. overview — обзор 2×. Это дизайн, в Minecraft не тестировался.

## Источники
stormworld-rp.zip: assets/reallyworld/textures/gui/gui_bg.png — оригинальная рамка, SW, металлический заголовок и инвентарь. Превью содержимого копирует исходный слот (47,165) размером 18×18. Изучены free_rewards, codes, rewards_playtime, reward_contents, wheel GUI, font/default.json и прежние daily-rewards. Полный список GUI/шрифтов и JSON — source-audit.txt. Архив содержит 1979 записей; рабочие ресурсы не изменялись.

## Сетка
Координаты относительно PNG. Контракт нового 54-slot chest: origin=(39,28), первый ItemStack=(47,46), шаг 18. Hitbox слота 16×16; декоративная ячейка 18×18. Slot=9*row+column, row 0..5, column 0..8. ItemStack игрока начинается (47,166); исходная нижняя рамка сохранена. Фон необходимо позиционировать по этому контракту, а не копировать смещение старого меню. Существующие font glyph height=256/ascent=40 требуют проверки и нового смещения при интеграции. Глифы и JSON не добавлялись.

## Области клика
- Главное: PvP x47..118/y46..99, строки 0..2, колонки 0..3; история x137..208/y46..99, строки 0..2, колонки 5..8. Зарплата и кейс — те же колонки, строки 3..5/y100..153. Колонка 4 неактивна.
- Пресеты: x47..100,101..154,155..208, y46..135; колонки 0..2 / 3..5 / 6..8, строки 0..4. Назад slots45..46; остальные нижние слоты — статус.
- Детали: ItemStack preview slots9..35, x47+18c/y64+18r, 16×16. Сетка содержит 27 ячеек демонстрационного превью; размер полного пресета будет определён отдельно. Назад slot45, использовать46..48, перезаписать49..51, удалить52..53. Кнопки y136..153. Строка 4 информационная. Иконки меча на карточках — статические символы функции, не содержимое пресета.
- История: строки 0..4, каждая высотой18. Информация в колонках0..4, действие в5..8 (x137..208). Назад45..46; строка5 информационная. Названия миров и время демонстрационные.
- Зарплата/кейс: назад45..46, получение47..53 (x83..208/y136..153). Остальные слоты неактивны.
Визуальная рамка кнопки включает промежутки между слотами; они не являются самостоятельными hitbox. Будущая реализация должна использовать прозрачные предметы для действий и блокировать перенос предметов в меню.

## Статика и динамика
Корневые PNG — законченные демонстрационные экраны. backgrounds — версии без изменяемых значений: счётчик, сумма, сроки, мир и время. Для реализации эти надписи выводятся отдельным текстовым слоем; шрифтовые провайдеры этого этапа не менялись. Никаких динамических ItemStack в PNG нет. Превью набора заполняется сервером отдельно; проверка наличия собственных ресурсов — будущая логика.
